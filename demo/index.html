what’s inside

One skill for each part of the animation workflow.

  • 01

    gsap-core

    Tweens, easing, stagger, defaults and matchMedia for reduced motion.

  • 02

    gsap-timeline

    Sequencing, labels and the position parameter (omitted means append at the end).

  • 03

    gsap-scrolltrigger

    Scroll-linked animation, pinning, scrub, batching and refresh/cleanup rules.

  • 04

    gsap-plugins

    Registration plus Flip, Draggable, ScrollSmoother, SplitText, SVG and eases.

  • 05

    gsap-utils

    clamp, mapRange, normalize, snap, wrap, pipe and friends.

  • 06

    gsap-react

    useGSAP, refs, gsap.context() and cleanup on unmount.

  • 07

    gsap-frameworks

    Vue, Nuxt, Svelte and SvelteKit lifecycle and cleanup patterns.

  • 08

    gsap-performance

    Transforms over layout, avoiding thrashes, will-change and batching.

scroll-driven

Timeline → ScrollTrigger → Plugins.

Scroll to scrub the strip. The section is pinned; the track moves on x only.

01

Timeline

One master timeline owns the sequence, with defaults and labels instead of chained delays.

02

ScrollTrigger

Pin the section, scrub 1, and use a function end plus invalidateOnRefresh so the distance recalculates.

03

Plugins

Register ScrollTrigger once. Batch the card reveals and clean up with matchMedia().revert().

the pattern used here 
const tl = gsap.timeline({
  scrollTrigger: {
    trigger: ".pin-section",
    start: "top top",
    end: () => "+=" + distance(),
    pin: true,
    scrub: 1,
    invalidateOnRefresh: true,
  },
});

tl.to(".pin-track", {
  x: () => -distance(),
  ease: "none",
});
